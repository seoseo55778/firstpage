# Портфолио Гордея Гежи

Одностраничный сайт SEO-специалиста: кейсы с цифрами, компетенции, софт и кнопка **Написать в Telegram**.

Дизайн в духе тёмных агентских лендингов (крупная типографика Unbounded, лаймовый акцент, аккордеон кейсов, бегущая строка инструментов) — не копия референсов Cosmos-Web / Atwinta, а та же плотность и ритм.

## Запуск

```bash
npm install
npm run dev -- --port 43141 --hostname 0.0.0.0
```

Откройте [http://localhost:43141](http://localhost:43141).

Сборка:

```bash
npm run build
npm start -- --port 43141
```

## Контент

Тексты и ссылки лежат в `src/content/site.ts`. Telegram: `https://t.me/gordeigezha`.

Графики из документа с кейсами — в `public/cases/`.

Из публичного блока компетенций убрана формулировка про «накрутку ПФ»: на сайте остаются UX, скорость и коммерческие факторы, как в рабочих кейсах.

Кейсы 6–7 из документа были без описания — на сайт не выносил. Когда будет текст и цифры, их можно добавить в тот же `site.ts`.
